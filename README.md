# 🎯 Squash

An AI-assisted coding education platform: adaptive challenges, skill assessment, and code correction quizzes powered by ML services.

## 🚀 Quick Start (Minimal)
```bash
cp lib/env_config.example.dart lib/env_config.dart   # create local env file
flutter pub get                                      # fetch Dart deps
flutter run                                          # launch app (emulator/device)
```
Fill placeholders in `lib/env_config.dart` before first run. See **`ENV_SETUP.md`** for details.

## 🧩 Features
- Interactive coding challenges & skill assessment
- Code similarity scoring & feedback
- Buggy code quizzes (generated by Code Corruptor)
- Progress & adaptive difficulty

## 🏗️ Architecture (High Level)
```
Flutter UI → REST calls → Python ML APIs → Models & Data
```
Loose coupling: Flutter only knows HTTP endpoints; ML stack evolves independently.

## 📂 Key Directories
```
lib/        Flutter app (screens, services, models)
ml_models/  Python ML modules (similarity, corruptor, classifier)
data/       Datasets (raw & processed)
docs/       Extended guides & references
```

## 🤖 ML Models Overview
See `ml_models/README.md` for full details.

## 🔧 Local ML APIs (Optional)
```bash
cd ml_models/code_similarity && python api.py   # Port 5000
cd ml_models/code_corruptor  && python api.py   # Port 5001
cd ml_models/skill_classifier && python api.py  # Port 5002 (after API added)
```
Android emulator uses `http://10.0.2.2:<port>` to reach host.
